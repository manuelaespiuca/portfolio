# Portfolio ʚ ɞ

🇧🇷 [Leia em português](README.md)

My personal portfolio website, built with plain HTML, CSS and JavaScript, no frameworks.

| Information | Details |
|---|---|
| **Field** | software development, QA, game development and UX/UI |
| **Stack** | plain HTML, CSS and JavaScript |
| **Languages** | Portuguese and English (PT / EN button) |
| **Theme** | light and dark, follows the system until the visitor picks one |
| **Fonts** | Outfit, Playfair Display, Hanken Grotesk, Caveat and Silkscreen (Google Fonts) |

## Features

- Light and dark theme, saved in the browser
- Portuguese and English, switched without reloading the page (the choice is saved too)
- Typing effect on the title and camera details over the photo, with a zoomed-in crop of the wings
- Projects on a desktop: draggable folders that open windows with a description, technologies and a link to the code
- Desktop grid that fades where the mouse passes
- Certifications with a filter by area and a see-all button
- Draggable stars, reading progress bar, sections that appear on scroll and a back-to-top button
- Respects `prefers-reduced-motion`
- Contact form that opens the email app with the message ready

## Project structure

```
.

├── README.md                        # Portuguese version
├── README-en.md

    ├── pastas.js                    # project folders and windows on the desktop

    └── grade.js                     # grid that reacts to the mouse
```
