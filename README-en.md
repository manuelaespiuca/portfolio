# Portfolio ʚ ɞ

🇧🇷 [Ler em português](README.md)

My personal portfolio website, built with plain HTML, CSS and JavaScript, no frameworks.

| Info | Details |
|---|---|
| **Focus** | software development, front-end, UX/UI and game development |
| **Stack** | plain HTML, CSS and JavaScript |
| **Languages** | Portuguese and English (PT / EN button) |
| **Theme** | light and dark, follows the system until the visitor chooses |
| **Fonts** | Bricolage Grotesque, Hanken Grotesk and Caveat (Google Fonts) |

## Features

- Light and dark theme, saved in the browser
- Portuguese and English, switched without reloading the page
- Project carousel, with keyboard arrows and swipe on mobile
- Certifications with a filter by area
- Draggable stars, reading progress bar and back-to-top button
- Respects `prefers-reduced-motion`
- Contact form that opens the email app with the message ready
