# Portfólio ʚ ɞ

🇺🇸 [Read in English](README-en.md)

Meu site de portfólio pessoal, feito com HTML, CSS e JavaScript puro, sem frameworks.

| Informações | Detalhes |
|---|---|
| **Área** | desenvolvimento de software, front-end, UX/UI e desenvolvimento de jogos |
| **Stack** | HTML, CSS e JavaScript puro |
| **Idiomas** | português e inglês (botão PT / EN) |
| **Tema** | claro e escuro, segue o sistema até a pessoa escolher |
| **Fontes** | Bricolage Grotesque, Hanken Grotesk e Caveat (Google Fonts) |

## Funcionalidades

- Tema claro e escuro, salvo no navegador
- Português e inglês, trocados sem recarregar a página
- Projetos em carrossel, com setas do teclado e deslize no celular
- Certificações com filtro por área
- Estrelas arrastáveis, barra de progresso de leitura e botão de voltar ao topo
- Respeita `prefers-reduced-motion`
- Formulário de contato que abre o app de e-mail com a mensagem pronta

## Estrutura do projeto

```
.
├── index.html                       # página principal
├── README.md
├── README-en.md                     # versão em inglês
├── assets/                          # imagens (favicon, asas, mascote)
├── css/
│   └── style.css                    # estilos e temas
├── js/
│   ├── main.js                      # relógio, tema, idioma, projetos, certificações, estrelas, formulário
│   └── extras.js                    # progresso, voltar ao topo, animações, brilho nos cards, teclado e swipe
└── versao-arquivo-unico/
    └── portfolio-interativo.html    # a mesma página em um único arquivo
```
