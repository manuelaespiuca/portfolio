# Portfólio ʚ ɞ

🇺🇸 [Read in English](README-en.md)

Meu site de portfólio pessoal, feito com HTML, CSS e JavaScript puro, sem frameworks.

| Informações | Detalhes |
|---|---|
| **Área** | desenvolvimento de software, QA, desenvolvimento de jogos e UX/UI |
| **Stack** | HTML, CSS e JavaScript puro |
| **Idiomas** | português e inglês (botão PT / EN) |
| **Tema** | claro e escuro, segue o sistema até a pessoa escolher |
| **Fontes** | Outfit, Playfair Display, Hanken Grotesk, Caveat e Silkscreen (Google Fonts) |

## Funcionalidades

- Tema claro e escuro, salvo no navegador
- Português e inglês, trocados sem recarregar a página (a escolha também fica salva)
- Efeito de digitação no título e detalhes de câmera sobre a foto, com recorte ampliado das asas
- Projetos numa área de trabalho: pastas arrastáveis que abrem janelas com descrição, tecnologias e link para o código
- Grade da área de trabalho que some onde o mouse passa
- Certificações com filtro por área e botão de ver todas
- Estrelas arrastáveis, barra de progresso de leitura, seções que aparecem ao rolar e botão de voltar ao topo
- Respeita `prefers-reduced-motion`
- Formulário de contato que abre o app de e-mail com a mensagem pronta

## Estrutura do projeto

```
.
├── index.html                       # página principal
├── README.md
├── README-en.md                     # versão em inglês
├── assets/                          # imagens (favicon, foto, asas, foto dos projetos)
├── css/
│   └── style.css                    # estilos e temas
└── js/
    ├── main.js                      # tema, idioma, digitação, certificações, estrelas, formulário
    ├── interacoes.js                # barra de progresso, voltar ao topo e seções ao rolar
    ├── pastas.js                    # pastas e janelas de projetos na área de trabalho
    ├── hud-asas.js                  # detalhe ampliado das asas
    └── grade.js                     # grade que reage ao mouse
```
